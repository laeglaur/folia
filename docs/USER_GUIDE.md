# Folia 使用说明

本说明随应用提供，可离线阅读。Mac：Cmd = ⌘，Option = ⌥，Shift = ⇧；正文中的 Cmd/Ctrl 表示 Mac 使用 Command，Windows/Linux 使用 Ctrl。快捷键作用于当前有焦点的区域。

## 首次安装后无法打开？

当前安装包尚未经过 Apple 公证。若出现 **Apple 无法验证“folia”是否包含可能危害 Mac 安全或泄漏隐私的恶意软件**：

1. 将 folia 拖入 **Applications（应用程序）**，先尝试打开一次。
2. 出现上述弹窗后，点击 **问号**，在帮助中选择 **为我打开“隐私与安全性”设置**。
3. 在 **安全性** 区域找到 folia 的拦截提示，点击 **仍要打开**（或对应的允许按钮），按提示确认身份并打开。

也可手动进入 **系统设置 → 隐私与安全性** 完成第 3 步；不同 macOS 版本的按钮文字可能略有不同。仅对从本仓库下载、且你信任的安装包这样操作。若提示明确为“包含恶意软件”“将损坏电脑”或“已损坏”，请先反馈具体提示，不要按此流程绕过。

## 阅读顺序

先看快速上手和页面整理；图片、表格、终端、日历与外观按需阅读。完整快捷键和输入规则集中在后半部分。

## 从第一条笔记开始

1. 在左栏新建笔记本和页面，或按 Cmd+N 快速新建页面。
2. 在“写点什么”输入，按 Shift+Enter 保存为 block。开启 Newest first 时输入区在上方，关闭后位于已有内容下方。
3. 点击已有 block 继续编辑；用左侧拖动区域排序，用折叠按钮收起。点击日期把常用内容收藏到左栏。
4. 右下角小鱼中，打开“外观调整”选主题，或打开 Toolbar 使用格式工具。

优先推荐 **Tilted Paper** 和 **Paper Collage**。笔记本组织页面，页面包含多个 block；侧栏收藏、独立桌面窗口与系统小组件是不同功能。

## 整理笔记本与页面

- **创建与重命名**：左栏顶部增加按钮创建笔记本，笔记本旁的增加按钮创建页面。双击笔记本或页面名称重命名；当前页标题也可直接修改。
- **展开与视图**：笔记本默认折叠，点击箭头展开。Files 是页面树，Thumbnails 是页面缩略图；它们不是正文主题切换。
- **多选**：Cmd/Ctrl+点击切换选择，Shift+点击选择同层连续页面。多选后右键可批量设置图标、复制、删除、开窗和移动。
- **移动**：拖动页面调整位置，或右键 → Move…，搜索并选择笔记本根目录或目标父页面。选中页面时 Tab / Shift+Tab 调整层级。
- **复制**：页面右键 Duplicate Page(s) 复制页面树；笔记本右键 Duplicate notebook 复制笔记本。焦点在侧栏时 Cmd/Ctrl+C、V 用于复制粘贴页面，文字输入框中仍是文字复制粘贴。
- **删除**：右键 Delete 或选中后 Option/Alt+Backspace；删除页包含其子页面。回收站可恢复，Empty trash 则永久清空。最后一个笔记本的删除按钮不可用。

## 设置 emoji 与个性标识

| 想修改什么 | 入口 |
| --- | --- |
| 笔记本图标 | 右键笔记本 → **Set emoji** |
| 页面图标 | 右键页面 → **Set Icon** |
| 多个页面图标 | 先多选页面，再右键 → **Set Icon**，应用同一个图标 |
| 清除图标 | 选择器底部 **Clear emoji**；笔记本菜单也提供清除入口 |

选择器支持分类浏览、最近使用与搜索。搜索匹配 emoji 本身、英文名称及分类；不保证中文关键词都可检索。选择后立即应用，关闭选择器不改变当前图标。

这些是笔记本或页面的标识，不会把 emoji 插入正文。Native Garden 的品牌 Logo 另有操作：点击 Logo 选择本地图片，右键恢复默认；品牌文字双击编辑。纸张主题的文字和装饰设置见“按外壳调整外观”。

## 快速新建页面

在主窗口按 **⌘N（Windows/Linux：Ctrl+N）**，会在选中的笔记本中新建顶层空白页；未选中笔记本时使用当前页面所属笔记本。自动展开左栏与目标笔记本，并选中标题，直接输入即可命名。卡片窗口和弹出的说明窗口不触发此操作。

## 正文书写与格式

- **新增文字块**：在“写点什么”中输入，按 ⇧ Enter 或点击 Add block。编辑已有块时，⇧ Enter 保存并结束本次编辑。
- **⌘ B / ⌘ I / ⌘ U**：选中文字后切换加粗、斜体、下划线。
- **⌘ H / ⌘ D / ⌘ E**：正文中分别切换高亮、删除线、行内代码。
- **⌘ Z / ⌘ ⇧ Z**：撤销 / 重做编辑。
- **Tab / ⇧ Tab**：增加 / 减少缩进，适用于列表、文本块和代码块。
- **⌘ ↑ / ⌘ ↓**：在已有正文块中，将整块向上 / 向下移动。
- **⌥ Backspace**：删除当前正文块；可在小鱼的 Trash 中恢复。
- **代码与引用**：段首输入 ``` 或 /code 后按 Enter 创建代码块；输入 > 或 /quote 后按空格创建引用。
- **更多格式**：在小鱼中打开 Toolbar，使用标题、列表、待办、表格、公式、附件等工具。先选中文字，再点击格式按钮。

## 混合缩进列表

同一棵缩进树可混用普通 bullet、编号和待办。将光标放在某一项中，在当前行开头输入 `-` / `1.` / `[]` 后按空格，或使用工具栏的列表 / 编号 / 待办按钮，转换当前项；选中多个同级项可一起转换。其他同级项和原有子树保持不变。Tab 缩进，Shift+Tab 反缩进，支持跨列表类型。

## 图片插入、缩放与标注

- 在正文中输入 `/at `（末尾空格）或点击格式工具栏的附件按钮，选择本地图片。图片以图片节点插入；其他附件类型按相应媒体或附件处理。工具栏可在小鱼中开启。
- `/link ` 可输入链接或媒体 URL；正文图片与“外观调整”中的背景图片是不同用途，后者不会插入笔记内容。
- 将鼠标放到图片**右下角**，出现缩放光标后拖动调整大小。选中图片后，Tab / Shift+Tab 调整缩进。
- **双击图片**打开标注窗口，支持矩形、椭圆、线段、箭头、画笔和文字。可设置颜色、笔画宽度或文字字号，并切换高亮样式。
- 标注工具栏提供撤销、重做、删除选中标注、**Save** 和 **Cancel**。完成标注后点击 Save 保存；不要把关闭窗口当作保存。
- 标注作为图片节点的数据保存，可再次双击修改；这不是直接覆盖本地原图文件的操作。它也不是裁剪、滤镜或像素级修图工具。

## 表格插入与编辑

1. 段首输入 `/table ` 或 `[[[ `，或点击格式工具栏的 **Table** 按钮，插入带表头的 3×3 表格。
2. 点击单元格开始输入，也可以在单元格内选中文字设置格式。
3. 光标位于表格内时出现表格控制条：**+ row** 在当前行后加行，**+ col** 在当前列后加列，**- row / - col** 删除选中的行 / 列，**del** 删除整张表。
4. 鼠标移到列边界，拖动调整列宽；宽度会随内容保存。表格边缘还可用于选中整张表，不要把边缘点击误当成单元格内定位。

当前界面没有合并或拆分单元格按钮，也不是电子表格：没有单元格计算公式、筛选或数据透视操作。正文数学公式与电子表格计算是两回事。

## iTerm2 原样粘贴与编辑

- **复制与粘贴**：在 iTerm2 用 ⌘⌥C（Copy with Styles）复制。回到正文，⌘V 使用普通粘贴；⌘⌥V 保留终端原始颜色和格式。
- **浏览器与桌面版**：浏览器需要剪贴板提供 HTML 并允许读取。只有 RTF 时请使用桌面版。
- **修改文字**：双击片段或点击“编辑文字”。鼠标拖选文字后，可修改文字颜色、底色、字号、加粗、斜体、下划线和删除线。
- **一键高亮**：浅黄 / 浅绿预设同时应用底色与配套深色文字。无选区时设置后续输入样式；“清除底色”只清除背景，文字颜色可单独修改。
- **⌥ ⇧ ← / →**：按词扩展选区。
- **⌘ ⇧ ← / →**：选择到行首 / 行尾。⌘ ⇧ ↑ / ↓ 选择到片段开头 / 末尾。
- **⌘ B / ⌘ I / ⌘ U**：片段内切换加粗、斜体、下划线。片段中的 ⌘ ↑ / ↓ 用于移动光标，不移动正文块。
- **完成与转换**：修改实时保存；点击“完成编辑”或按 Esc 退出。点击“转为普通文本”后，文字改为跟随正文主题。
- **保留格式**：使用 Backup 保留片段颜色。Markdown 导出为纯文本代码块，不保留颜色。

## 查找、侧栏与页面

- **⌘ F / Esc**：打开 / 关闭当前页查找。侧栏搜索用于查找笔记内容。
- **⌘ [ / ⌘ ]**：展开或收起左侧栏 / Contents。
- **页面与笔记本**：使用左侧栏的增加按钮创建内容；页面右键菜单提供页面操作。
- **选中侧栏页面后**：⌘C、⌘V 复制页面；Tab / ⇧ Tab 调整页面层级；⌥ Backspace 删除选中的页面或笔记本。这些操作不在文字输入框中触发。
- **Contents**：点击目录条目跳转到对应内容。小鱼中的 Sidebar、Contents 也可控制两侧栏显示。

## Contents 列表项开关

小鱼 → 视图 → **Contents 显示列表项**：默认关闭，不显示列表的嵌套分组条目；打开后恢复原有列表目录。页面标题、正文块摘要和标题目录不受影响。设置会在本机记住，对所有外壳主题生效。

## 页面属性与日期

小鱼中的 **Metadata** 控制页面属性显示。属性区的 **+** 添加字段，输入名称并选择类型：text、long text、date、date range、select、multi-select。右键已有字段可切换类型。

点击字段值编辑；长文本失焦保存，也可 Cmd/Ctrl+Enter 结束编辑。日期范围有开始与结束值；这些日期字段可供日历选择。隐藏 Metadata 只是隐藏界面，不会删除属性。字段类型按笔记本维护，同名字段的类型并非只影响当前页。

## 日历视图与页面日期

1. 在左栏右键笔记本，勾选 **Calendar view**，该笔记本使用页面日历视图；再次取消可关闭。配置按笔记本保存。
2. **Date** 选择用于排入日历的日期来源，默认是页面创建日期（Created at）；也可以使用页面元数据中的日期字段。可同时选择多个来源，至少保留一个。
3. **Fields** 勾选日历条目展示的元数据字段；双击字段标签，以该字段的值区分颜色。
4. 使用月份左右箭头切换月份；点击页面条目打开页面。日期范围会画成跨日条带。
5. 点击某天的 **+** 新建顶层页面，并写入该天的 `date` 元数据。若原来按创建日期排列，会自动改为按 `date` 排列。若使用其他自定义日期来源，新页面仍写入 `date`，需选择该来源或补填相应自定义字段才能在预期日期看到它。

日历也有按 block 日期展示的模式，与上面的页面日期日历不同：点击条目跳转到对应页面的 block，每日最多显示两条摘要，更多数量以 `+N` 提示，并非完整展开列表。日历不是提醒或定时通知功能。

## 点击日期收藏与 Pinned 卡片

- 点击正文 block 的**日期文字**，切换收藏 / 取消收藏；已收藏内容出现在左栏 **Pinned** 区。
- 点击 Pinned 卡片打开桌面浮窗；右键卡片可打开原页面或取消收藏。取消收藏不会删除原 block。
- 桌面浮窗顶部可拖动；双击顶部收起或展开内容。关闭窗口不会删除原笔记。
- 页面右键菜单的 **Pin First Block** 收藏该页首个 block，不是收藏整页所有内容。
- 日期旁单独的**图钉图标**用于“显示到 macOS 桌面小组件”，与侧栏收藏不同。浏览器预览不能更新系统小组件。

## macOS 桌面小组件

在 folia 桌面版中点击 block 日期旁的图钉，再到桌面右键 → 编辑小组件，添加 **folia Block**。未指定 Block 的小组件跟随应用中的钉选；手动指定 Block 后固定显示该块。

小组件支持文字、列表、图片预览和 iTerm2 原样片段的等宽文字及颜色。图片需能在应用内正常读取；无法读取时显示图片提示。内容从开头显示，超出小组件尺寸会截断；小组件不能滚动，推荐使用大号卡片或打开完整窗口。

小组件搜索入口打开独立选择窗口，可搜索并“显示到小组件”，也可“打开完整窗口”编辑指定 block。它与侧栏收藏是两套操作：点击 block 日期收藏到侧栏，日期旁图钉用于发送到系统小组件。

正文修改会触发自动同步，但屏幕刷新由 macOS 调度，不能保证逐字实时刷新。小组件是只读预览，修改内容请回到 folia。升级后请退出再打开桌面版，避免旧进程继续发送旧格式数据。

## 按外壳调整外观

推荐先试 **Tilted Paper**（留白、倾斜纸框）和 **Paper Collage**（亚麻、毛边纸张与拼贴）。若需要基础商务风，可选 **Typora Base**；**Garden Typora** 是基础布局的轻度变化。正文主题仍可独立搭配。

小鱼菜单中的「外观调整」打开可拖动面板，Shell、正文主题及对应外观细节统一在面板中设置，调整时可以查看页面变化。设置项随当前 Shell 切换，各个 Shell 分别保存：

- Native Garden / Garden Typora：背景颜色、背景图片和图片透明度。
- Tilted Paper：桌面背景、纸色、阴影、三个框的倾斜角度、左下图片和文字，不提供树叶开关。
- Paper Collage：桌面背景、纸色、阴影、正文纸张角度、左下图片、右侧挂画和树叶装饰；品牌、左下文字和右侧题字在页面上双击编辑。
- Typora Base：沿用正文主题外观，不提供拼贴装饰设置。

背景、左下图片和挂画支持粘贴 URL 或点击“选择本地图片”；“清除图片”恢复该区域的默认图案（若有）。桌面版将导入图片存入应用资源目录；浏览器预览会缩小并压缩图片，保存在该浏览器本地。

「恢复默认外观」只重置外观，不清空已编辑的文字。主题偏好和文字位置保存在当前设备，JSON 笔记备份不包含这些设置。

各主题左栏顶部文字统一双击原位编辑，位置固定。Tilted 和 Collage 的左下文字、右侧题字可双击编辑：拖动上边框移动，拖动右下角方形手柄缩放，拖动上方圆形手柄旋转。Enter 或点击外部保存，Shift + Enter 换行，Esc 取消文字修改。位置、大小和角度自动保存。Tilted 的题字与署名位于同一文本框，可一并编辑。

## 主题、文件与恢复

- **外观调整**：小鱼中的入口打开独立面板，主题和背景细节集中在这里。
- **视图开关**：Toolbar 控制格式工具；Metadata 控制页面属性；Newest first 控制块排列方向；Sidebar / Contents 控制两侧栏。
- **导入**：Import MD 选择文件，Import folder 选择整个文件夹。打开外部 Markdown 时，若显示 **Temporary MD**，点击 **Save to Notebook** 才将临时页面保存到笔记本。
- **导出**：Markdown 用于通用文本；Backup 导出 JSON 笔记数据，可保留终端片段颜色。外观偏好独立保存在本机，不在笔记备份中；桌面迁移还应保留媒体资源。
- **页面历史**：Restore page 恢复当前页的上一个已保存版本，会先要求确认，并保留当前保存版本为历史记录；不是任意版本浏览器。
- **回收站**：点击 Trash 条目恢复；Empty trash 永久清空。它与编辑器的 Cmd+Z 撤销不同。

## 编辑区快捷键

| 快捷键 | 当前行为 |
| --- | --- |
| `Tab` | 缩进列表项；也支持图片、视频、音频等媒体缩进 |
| `Shift+Tab` | 反缩进列表项；也支持媒体反缩进 |
| `Shift+Enter` | 在 composer 里提交为 block；在已有 block 或卡片里保存并退出编辑 |
| `Cmd/Ctrl+B` | 加粗 |
| `Cmd/Ctrl+I` | 斜体 |
| `Cmd/Ctrl+U` | 下划线 |
| `Cmd/Ctrl+D` | 删除线 |
| `Cmd/Ctrl+Shift+S` | 删除线，兼容 Tiptap 默认快捷键 |
| `Cmd/Ctrl+E` | 行内代码 |
| `Cmd/Ctrl+H` | 高亮 |
| `Cmd/Ctrl+Alt+1..6` | 标题 1 到标题 6 |
| `Cmd/Ctrl+Alt+0` | 普通段落 |
| `Cmd/Ctrl+Shift+7` | 编辑器默认有序列表切换；按当前项混排请使用 `1. ` |
| `Cmd/Ctrl+Shift+8` | 编辑器默认无序列表切换；按当前项混排请使用 `- ` |
| `Cmd/Ctrl+ArrowUp/ArrowDown` | 移动当前 block 上下位置 |
| `Option/Alt+Backspace` | 删除当前 block |

`Cmd+[` / `Cmd+]` 切换 Sidebar / Contents（普通输入框中不触发）；编辑区缩进使用 `Tab` / `Shift+Tab`。

## 自动触发规则

| 输入 | 触发 |
| --- | --- |
| `**text**` 或 `__text__` | 加粗 |
| `*text*` 或 `_text_` | 斜体 |
| `` `code` `` | 行内代码 |
| `~~text~~` | 删除线 |
| `~text~` | 下划线，项目自定义 |
| `$x+y$` | 行内公式，不是公式块 |
| `$$ ` 或 `/math ` | 公式块 |
| `$$` 后按 Enter，或 `/math` 后按 Enter | 公式块 |
| `[] ` 或 `【】 ` | 待办列表，项目自定义 |
| `- [ ] ` / `- [x] ` | 默认任务列表规则 |

## 使用范围与容易混淆的操作

- 正文的 Shift+Enter 提交新块或保存已有块；原样终端片段使用“完成编辑”或 Esc 结束编辑。
- 原样终端片段的 Enter 换行，Tab 插入制表符，Cmd+Z / Cmd+Shift+Z 撤销和重做。
- 原样终端片段：Option+左右键按词移动，Command+左右键到行首/行尾，Command+上下键到片段开头/末尾；加 Shift 扩展选区。
- 正文的 Command+上下键移动整个块；不要将它当作终端片段的光标移动。
- 终端片段使用自身工具栏设置删除线、高亮和字号；正文的 Cmd+H / Cmd+D / Cmd+E 不作为终端片段格式快捷键。
- 当前页刚删除的块，可在焦点不处于输入框时用 Cmd+Z 恢复；也可使用 Trash 恢复。
- 点击正文块或列表项旁的折叠按钮收起内容；点击 Pin 可固定块，桌面小组件按钮用于桌面版展示。
- 媒体可通过工具栏附件按钮插入；选中媒体后可调整大小，Tab / Shift+Tab 调整缩进。

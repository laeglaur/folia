# Folia 使用说明

本说明随应用提供，可离线阅读。Mac：Cmd = ⌘，Option = ⌥，Shift = ⇧；正文中的 Cmd/Ctrl 表示 Mac 使用 Command，Windows/Linux 使用 Ctrl。快捷键作用于当前有焦点的区域。

## 编辑区快捷键

| 快捷键 | 当前行为 |
| --- | --- |
| `Tab` | 缩进列表项；也支持图片、视频、音频等媒体缩进 |
| `Shift+Tab` | 反缩进列表项；也支持媒体反缩进 |
| `Shift+Enter` | 在 composer 里提交为 block；在已有 block 或卡片里保存并退出编辑 |
| `Cmd/Ctrl+B` | 加粗 |
| `Cmd/Ctrl+I` | 斜体 |
| `Cmd/Ctrl+U` | 下划线 |
| `Cmd/Ctrl+D` | 删除线 |
| `Cmd/Ctrl+Shift+S` | 删除线，兼容 Tiptap 默认快捷键 |
| `Cmd/Ctrl+E` | 行内代码 |
| `Cmd/Ctrl+H` | 高亮 |
| `Cmd/Ctrl+Alt+1..6` | 标题 1 到标题 6 |
| `Cmd/Ctrl+Alt+0` | 普通段落 |
| `Cmd/Ctrl+Shift+7` | 编辑器默认有序列表切换；按当前项混排请使用 `1. ` |
| `Cmd/Ctrl+Shift+8` | 编辑器默认无序列表切换；按当前项混排请使用 `- ` |
| `Cmd/Ctrl+ArrowUp/ArrowDown` | 移动当前 block 上下位置 |
| `Option/Alt+Backspace` | 删除当前 block |

`Cmd+[` / `Cmd+]` 切换 Sidebar / Contents（普通输入框中不触发）；编辑区缩进使用 `Tab` / `Shift+Tab`。

## 自动触发规则

| 输入 | 触发 |
| --- | --- |
| `**text**` 或 `__text__` | 加粗 |
| `*text*` 或 `_text_` | 斜体 |
| `` `code` `` | 行内代码 |
| `~~text~~` | 删除线 |
| `~text~` | 下划线，项目自定义 |
| `$x+y$` | 行内公式，不是公式块 |
| `$$ ` 或 `/math ` | 公式块 |
| `$$` 后按 Enter，或 `/math` 后按 Enter | 公式块 |
| `[] ` 或 `【】 ` | 待办列表，项目自定义 |
| `- [ ] ` / `- [x] ` | 默认任务列表规则 |
| `- ` / `+ ` / `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `# ` 到 `###### ` | 标题 |
| `> ` 或 `/quote ` | 引用块 |
| <code>```</code> 或 `/code ` | 代码块 |
| <code>```</code> 或 `/code` 后按 Enter | 代码块 |
| `---` / `___ ` / `*** ` | 分割线 |
| `/table ` 或 `[[[ ` | 3x3 表格 |
| `/link ` | 弹窗输入链接或媒体 URL |
| `/at ` | 触发附件选择 |
| `/date ` | 插入当前日期时间 |

## 容易记错的点

- `-text-` 当前不会触发删除线。
- 删除线的自动触发写法是 `~~text~~`。
- `$text$` 当前是行内公式。
- 公式块是 `$$` 或 `/math`。

## 补充编辑快捷键

| 快捷键 | 适用范围与行为 |
| --- | --- |
| Cmd/Ctrl+A、C、X、V | 当前编辑区全选、复制、剪切、普通粘贴 |
| Cmd/Ctrl+Z | 撤销 |
| Cmd/Ctrl+Shift+Z 或 Cmd/Ctrl+Y | 重做 |
| Cmd/Ctrl+Alt+C | 正文切换代码块；在 iTerm2 中此键是 Copy with Styles |
| Cmd/Ctrl+Shift+9 | 编辑器默认待办列表切换；按当前项混排请使用 `[] ` |
| Cmd/Ctrl+Enter | 正文插入软换行；不是提交新块 |
| Enter | 正文换段、列表新增条目、代码块换行 |
| Option/Alt+Delete | 与 Option/Alt+Backspace 一样删除当前正文块 |

## 查找与弹出编辑器

| 按键 | 行为 |
| --- | --- |
| Cmd/Ctrl+F | 打开当前页查找 |
| 查找框内 Enter / ↓ | 下一个匹配 |
| 查找框内 ↑ | 上一个匹配 |
| Esc | 关闭查找或当前菜单 |
| 页面重命名时 Enter / Esc | 确认 / 取消重命名 |
| 公式编辑框 Enter / Esc | 结束公式编辑 |

## 正文书写与格式

- **新增文字块**：在“写点什么”中输入，按 ⇧ Enter 或点击 Add block。编辑已有块时，⇧ Enter 保存并结束本次编辑。
- **⌘ B / ⌘ I / ⌘ U**：选中文字后切换加粗、斜体、下划线。
- **⌘ H / ⌘ D / ⌘ E**：正文中分别切换高亮、删除线、行内代码。
- **⌘ Z / ⌘ ⇧ Z**：撤销 / 重做编辑。
- **Tab / ⇧ Tab**：增加 / 减少缩进，适用于列表、文本块和代码块。
- **⌘ ↑ / ⌘ ↓**：在已有正文块中，将整块向上 / 向下移动。
- **⌥ Backspace**：删除当前正文块；可在小鱼的 Trash 中恢复。
- **代码与引用**：段首输入 ``` 或 /code 后按 Enter 创建代码块；输入 > 或 /quote 后按空格创建引用。
- **更多格式**：在小鱼中打开 Toolbar，使用标题、列表、待办、表格、公式、附件等工具。先选中文字，再点击格式按钮。

## iTerm2 原样粘贴与编辑

- **复制与粘贴**：在 iTerm2 用 ⌘⌥C（Copy with Styles）复制。回到正文，⌘V 使用普通粘贴；⌘⌥V 保留终端原始颜色和格式。
- **浏览器与桌面版**：浏览器需要剪贴板提供 HTML 并允许读取。只有 RTF 时请使用桌面版。
- **修改文字**：双击片段或点击“编辑文字”。鼠标拖选文字后，可修改文字颜色、底色、字号、加粗、斜体、下划线和删除线。
- **一键高亮**：浅黄 / 浅绿预设同时应用底色与配套深色文字。无选区时设置后续输入样式；“清除底色”只清除背景，文字颜色可单独修改。
- **⌥ ⇧ ← / →**：按词扩展选区。
- **⌘ ⇧ ← / →**：选择到行首 / 行尾。⌘ ⇧ ↑ / ↓ 选择到片段开头 / 末尾。
- **⌘ B / ⌘ I / ⌘ U**：片段内切换加粗、斜体、下划线。片段中的 ⌘ ↑ / ↓ 用于移动光标，不移动正文块。
- **完成与转换**：修改实时保存；点击“完成编辑”或按 Esc 退出。点击“转为普通文本”后，文字改为跟随正文主题。
- **保留格式**：使用 Backup 保留片段颜色。Markdown 导出为纯文本代码块，不保留颜色。

## 查找、侧栏与页面

- **⌘ F / Esc**：打开 / 关闭当前页查找。侧栏搜索用于查找笔记内容。
- **⌘ [ / ⌘ ]**：展开或收起左侧栏 / Contents。
- **页面与笔记本**：使用左侧栏的增加按钮创建内容；页面右键菜单提供页面操作。
- **选中侧栏页面后**：⌘C、⌘V 复制页面；Tab / ⇧ Tab 调整页面层级；⌥ Backspace 删除选中的页面或笔记本。这些操作不在文字输入框中触发。
- **Contents**：点击目录条目跳转到对应内容。小鱼中的 Sidebar、Contents 也可控制两侧栏显示。

## 主题、文件与恢复

- **外观设置**：在小鱼中点击“外观调整”，在可拖动面板中选择外壳和正文主题；细节选项随外壳变化。
- **显示选项**：Toolbar 控制格式工具栏；Metadata 控制页面元信息；Newest first 控制块的排列顺序。
- **Import MD / Import folder**：导入 Markdown 文件，或选择整个文件夹导入。
- **Markdown / Backup**：Markdown 用于通用文本导出；Backup 用于保存完整笔记数据，包括原样终端片段的格式。
- **Restore page / Trash**：Restore page 恢复页面历史；点击 Trash 中的条目恢复删除内容。Empty trash 会永久清空回收站。

## 使用范围与容易混淆的操作

- 正文的 Shift+Enter 提交新块或保存已有块；原样终端片段使用“完成编辑”或 Esc 结束编辑。
- 原样终端片段的 Enter 换行，Tab 插入制表符，Cmd+Z / Cmd+Shift+Z 撤销和重做。
- 原样终端片段：Option+左右键按词移动，Command+左右键到行首/行尾，Command+上下键到片段开头/末尾；加 Shift 扩展选区。
- 正文的 Command+上下键移动整个块；不要将它当作终端片段的光标移动。
- 终端片段使用自身工具栏设置删除线、高亮和字号；正文的 Cmd+H / Cmd+D / Cmd+E 不作为终端片段格式快捷键。
- 当前页刚删除的块，可在焦点不处于输入框时用 Cmd+Z 恢复；也可使用 Trash 恢复。
- 点击正文块或列表项旁的折叠按钮收起内容；点击 Pin 可固定块，桌面小组件按钮用于桌面版展示。
- 媒体可通过工具栏附件按钮插入；选中媒体后可调整大小，Tab / Shift+Tab 调整缩进。

## Contents 列表项开关

小鱼 → 视图 → **Contents 显示列表项**：默认关闭，不显示列表的嵌套分组条目；打开后恢复原有列表目录。页面标题、正文块摘要和标题目录不受影响。设置会在本机记住，对所有外壳主题生效。

## macOS 桌面小组件

在 folia 桌面版中点击 block 日期旁的图钉，再到桌面右键 → 编辑小组件，添加 **folia Block**。未指定 Block 的小组件跟随应用中的钉选；手动指定 Block 后固定显示该块。

小组件支持文字、列表、图片预览和 iTerm2 原样片段的等宽文字及颜色。图片需能在应用内正常读取；无法读取时显示图片提示。内容从开头显示，超出小组件尺寸会截断；小组件不能滚动，推荐使用大号卡片或打开完整窗口。

小组件搜索入口打开独立选择窗口，可搜索并“显示到小组件”，也可“打开完整窗口”编辑指定 block。它与侧栏收藏是两套操作：点击 block 日期收藏到侧栏，日期旁图钉用于发送到系统小组件。

正文修改会触发自动同步，但屏幕刷新由 macOS 调度，不能保证逐字实时刷新。小组件是只读预览，修改内容请回到 folia。升级后请退出再打开桌面版，避免旧进程继续发送旧格式数据。

## 混合缩进列表

同一棵缩进树可混用普通 bullet、编号和待办。将光标放在某一项中，在当前行开头输入 `-` / `1.` / `[]` 后按空格，或使用工具栏的列表 / 编号 / 待办按钮，转换当前项；选中多个同级项可一起转换。其他同级项和原有子树保持不变。Tab 缩进，Shift+Tab 反缩进，支持跨列表类型。

## 快速新建页面

在主窗口按 **⌘N（Windows/Linux：Ctrl+N）**，会在选中的笔记本中新建顶层空白页；未选中笔记本时使用当前页面所属笔记本。自动展开左栏与目标笔记本，并选中标题，直接输入即可命名。卡片窗口和弹出的说明窗口不触发此操作。

## 按外壳调整外观

小鱼菜单中的「外观调整」打开可拖动面板，Shell、正文主题及对应外观细节统一在面板中设置，调整时可以查看页面变化。设置项随当前 Shell 切换，各个 Shell 分别保存：

- Native Garden / Garden Typora：背景颜色、背景图片和图片透明度。
- Tilted Paper：桌面背景、纸色、阴影、三个框的倾斜角度、左下图片和文字，不提供树叶开关。
- Paper Collage：桌面背景、纸色、阴影、正文纸张角度、左下图片、右侧挂画和树叶装饰；品牌、左下文字和右侧题字在页面上双击编辑。
- Typora Base：沿用正文主题外观，不提供拼贴装饰设置。

背景、左下图片和挂画支持粘贴 URL 或点击“选择本地图片”；“清除图片”恢复该区域的默认图案（若有）。桌面版将导入图片存入应用资源目录；浏览器预览会缩小并压缩图片，保存在该浏览器本地。

「恢复默认外观」只重置外观，不清空已编辑的文字。主题偏好和文字位置保存在当前设备，JSON 笔记备份不包含这些设置。

各主题左栏顶部文字统一双击原位编辑，位置固定。Tilted 和 Collage 的左下文字、右侧题字可双击编辑：拖动上边框移动，拖动右下角方形手柄缩放，拖动上方圆形手柄旋转。Enter 或点击外部保存，Shift + Enter 换行，Esc 取消文字修改。位置、大小和角度自动保存。Tilted 的题字与署名位于同一文本框，可一并编辑。
